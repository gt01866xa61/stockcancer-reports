市場判讀

盤很黏、沒有 FOMO，卻仍在收復失土：有數字的個股用漲一段、休息、再墊高的方式前進

重點七月底深跌時，主持人原估可能要到第四季甚至明年才收復；現在不少人已收回約一半。漲停追價隔日容易被修理，但波段與基本面標的仍逐步墊高，因此整體由觀望轉為相對樂觀。
我還是覺得其實這個盤算是蠻不錯的
盤面三層
  1. 情緒：沒有追漲就賺的全面 FOMO。
  2. 結構：強勢標的不連續，常漲一段後盤整。
  3. 基本面：有數字支撐者仍能逐步墊高。
操作區分
追漲停 搶短 波段 基本面個股
相對樂觀不等於每檔都能追；本集明確警告隔日反殺。
風險：若把慢漲誤認為落後補漲而追高，仍可能被無延續性的盤面修理。
應對：只追蹤有數字驗證的標的，等待盤整後再墊高，不用漲停板代替研究。
3/12
事件拆解

Google–Marvell 合作不只是一張權證：合作範圍瞄準 TPU 主晶片外圍的多種專用晶片

重點節目轉述合作涵蓋 attached to TPU ecosystem 的推論晶片、記憶體控制器、NIC 與 near-memory compute，重點是 main die 之外的周邊。權證約 7%、2033 年歸屬等條款只列為節目轉述，未冒充外部核實。
先分兩層
  1. 公開層：合作方向與廣泛周邊晶片範圍。
  2. 待驗層：行使價、稀釋比例、股東順位與營收歸屬細節。
  3. 投資層：真正決定價值的是量產、收入、毛利與持續年限。
可能範圍
Inference Memory Controller NIC Near-memory compute
Frozen、MPU、CPU 與約 million 級數量是主持人考察，公開資訊未必可見。
風險：把權證上限直接當成已持股比例，或把所有周邊晶片都算進近期營收，會嚴重高估。
應對：等待正式契約、財報與量產揭露，分別建模 vesting、收入與毛利，不用單一 TAM 倍乘。
4/12
商業模式

從 Turnkey 到 Full-COT：Google 把高價值環節抓回來，設計夥伴轉收 NRE、IP 與服務費

重點Turnkey 由夥伴包設計、HBM、基板、封裝、料件與投片，靠總包與逐項加價取得豐厚毛利；COT 則由 Google 自己掌握主晶片設計、光罩、關鍵料件採購乃至投片，外部夥伴做 I/O、SerDes、介面與設計服務。
決心要往COT的方向去走
價值鏈重分配
  1. Google：保留主晶片與高單價決策權。
  2. 設計夥伴：取得 NRE、IP 授權與工程服務收入。
  3. 供應鏈：封裝、投片與產能仍可能由有能力的夥伴協助。
兩種模式
Turnkey 總包 Semi-COT Full-COT Customer-Owned Tooling
COT 不等於外部夥伴消失；台積電產能與設計能力仍讓多夥伴模式有價值。
風險：客戶掌握更多價值鏈後，會更能規定供應商可賺的錢；服務收入的毛利結構不能照 turnkey 套用。
應對：模型分開估 NRE、IP、設計服務、封裝投片與料件加價，避免把兩種模式混成同一毛利率。
5/12
Marvell／聯發科

新增周邊晶片不等於搶走既有 TPU roadmap：短線 TAM 被分，長線案子可能變更多

重點主持人看到的 Marvell MPU、CPU、推論與搜尋特殊晶片偏向主晶片旁的新案，不是聯發科或 Broadcom 既有 V8／V9／V10 roadmap 的直接取代。更多參與者會壓縮未證實的未來 TAM 想像，但也反映 Google 正擴大硬體版圖。
判讀順序
  1. 先問是否從既有 roadmap 搶走。
  2. 再問是主晶片、周邊晶片或 IP／chiplet。
  3. 最後才估新增專案能否放量與貢獻毛利。
角色
Marvell MRVL 聯發科 AMD Google
AMD 參與 CPU chiplet／IP 的說法是市場傳聞；所有專案代號均不當作確定 design win。
風險：市場可能先交易競爭者增加，實際案子卻尚未證實；也可能反過來把所有新案都提前算成營收。
應對：以專案類型、既有或新增、量產時間與服務範圍四欄追蹤，不用一個總 TAM 包辦。
6/12
Broadcom

真正受壓的是 Turnkey 的肉：案子未必被奪走，但可總包、加價的範圍可能縮小

重點主持人認為把事件視為 Broadcom 的偏負面因素合理：Google 若把部分未來案子改走 COT，Broadcom 能從 HBM、基板、封裝與料件逐項加價的 turnkey 總量會下降。這不是既有主晶片 roadmap 已失守的證據。
負面從哪裡來
  1. 不是主晶片被直接換人。
  2. 而是客戶把更多高價值環節收回。
  3. 同一案子的可服務範圍與可加價項目變少。
需拆模型
主晶片設計 HBM 基板 封裝 Turnkey markup
主持人用五案中兩三案改走 COT 作情境例子，並非公司正式案量指引。
風險：只用事件把 Broadcom 整體轉空會過度延伸；需求強、IP 與大型專案能力仍可能保住重要案子。
應對：把 Broadcom 估值敏感度拆成案量、turnkey 比例、每案內容與毛利率，不只看客戶名單。
7/12
IC 設計服務

COT 不是設計服務末日：需求夠強時，小朋友也能分案，議價權仍來自替代機會與產能

重點Google 開更多晶片、把案子拆細後，Marvell、聯發科與其他 design house 可承接 NRE、IP、I/O、SerDes、記憶體介面、封裝與投片。主持人的結論是普遍有利 IC Design，Broadcom 因原模式太美好才相對吃虧。
夥伴仍有價值
  1. 設計與 IP 能力縮短開案時間。
  2. 卡到先進產能可協助客戶量產。
  3. 需求強時，供應商有其他客戶選項，不必無條件接受壓價。
收入池
NRE IP licensing Design service Packaging／tape-out
客戶可先算好供應商能賺多少；利多不等於毛利必然高於 turnkey。
風險：需求轉弱或產能鬆動後，客戶議價權會更大；設計服務業者也可能為搶案承擔前期成本。
應對：同時追蹤 backlog、NRE 認列、IP royalty、量產分潤、產能與客戶集中度。
8/12
Google 算力

從 Frontier Model House 到硬體房東：雲端租賃與 Token 生產，可能讓 Google 越開越多晶片

重點主持人認為 Google 仍做前沿模型，但更認真投入伺服器與雲端租賃、AI token 生產；當硬體端成為更可賺錢的存在，資源會推動更多自研晶片與 COT 專案，外部設計夥伴也可同步受惠。
正向循環
  1. 雲端與 token 需求增加硬體利用率。
  2. 更多硬體資源支持更多專用晶片。
  3. COT 降低每顆晶片的總包成本，再擴大專案數。
驗證端
Cloud rental Server rental AI token Custom silicon
晶片越開越多是主持人情境推演；仍須以量產、利用率與現金流驗證。
風險：CapEx 回收、雲端競爭與專案執行都可能拖慢循環；便宜開案不代表每顆都能商業成功。
應對：追蹤 Google Cloud 成長、CapEx、折舊、利用率、自研晶片量產與外部夥伴營收。
9/12
職涯與週期

全職投資沒有固定薪水；半導體終究均值回歸，真正的優勢是撐得到下一輪

重點全職投資換來時間自由，卻把所有收入與市場結果綁在自己身上，盤差時心理壓力可能比上班更大。半導體這輪很大仍是週期；錯過過去只是可惜，槓桿與集中讓自己出局才是永久損失。
重點是你有辦法活下來
生存條件
  1. 生活費與投資資金分離。
  2. 不把單一產業大週期視為永久成長。
  3. 預先限制集中度、槓桿與最大可承受回吐。
壓力來源
無固定收入 盤差 均值回歸 集中風險
全職投資不是不用工作，而是沒有保證薪水的另一份工作。
風險：用過去大多頭績效估生活費，可能在週期反轉時被迫低點變現。
應對：先準備生活緩衝、收入情境與停手機制，再評估全職；不要用全押補回錯過行情。

方法與出場

基本面當核心、技術面當工具；很會買但不會賣，就用均線與分批先機械化

重點主持人不否認看線、量能與動能也能賺錢；他仍以基本面為核心，只融入有效的技術工具，不整套切換。對買點強、賣點弱者，先把十日線或月線跌破後賣三成或五成寫成規則並回測。
從問題到規則
  1. 確認優勢在買點而非整套交易。
  2. 選一條均線與固定減碼比例。
  3. 用歷史交易回測，再以前瞻小部位驗證。
保留與吸收
基本面核心 圖形 量能 動能 均線出場
逐字稿的實力線依後文月線與出場語境校正為十日線；聽眾 72%／PF 1.6 原音未確證，不採用。
風險：用技術面替基本面壞化找藉口，或用基本面阻止規則出場，都是混合方法最常見的失控點。
應對：明定哪個訊號負責進場、加碼、減碼與否證，避免兩套方法只在虧損時互相救援。

行動清單

EP690 可直接執行的三欄框架

現在做

  • 把 Google 自研晶片合作拆成 main die、周邊晶片、NRE、IP、封裝與投片六欄。
  • 把當前盤面候選限制在已有基本面數字且能盤整墊高的標的。
  • 設定單一持股上限、生活資金隔離與週期反轉時的最大回吐。
  • 為不會賣的交易測試十日線／月線與三成／五成分批出場。

等待驗證

  • Google–Marvell 正式協議的權證條款、合作產品、收入歸屬與量產節奏。
  • Marvell 新案是否真為新增周邊晶片，而非既有 TPU roadmap 重分配。
  • Google 的 COT 比例提高後，Broadcom turnkey 內容與毛利是否實際下降。
  • AI 雲端利用率、Google Cloud 現金流與更多自研晶片是否形成正循環。

明確避免

  • 把節目轉述的 7%、2033 或晶片代號當成已核實公司公告。
  • 把 Broadcom 單一事件利空延伸成整家公司必然轉空。
  • 因錯過大週期而單壓一檔、借槓桿或動用必要生活資金。
  • 用私人朋友技法、聽眾回測數字或匿名公司線索冒充可複製答案。
