回撤現況

淨值回到 5 月初：25–28% 是警報，不是答案

重點主持人估計本輪 maximum drawdown 約 25–28%，今年高點曾有約 200%多報酬；這是大幅回吐，且尚無法確認回撤已結束。
判讀順序
  1. 先把目前損失當成已發生，不以成本價決定下一步。
  2. 評估部位是否已影響睡眠、生活與決策品質。
  3. 再比較指數與個股誰更有機會帶回下一段新高。
回撤背景
主持人淨值 DD 25–28% 同業高報酬案例 DD 50%+
25–28%是主持人口述估算，不是經會計或券商對帳後的精確績效數字。
即使已配置大量台積電與台指期，整體淨值仍明顯回撤。
風險：把過去最高報酬當安全墊，容易低估剩餘跌幅與流動性壓力。
應對：先以目前淨值重新計算可承受損失，不用高點部位反推該抱多久。

市場結構

櫃買近月跌逾 20%：沒有爆量，不代表賣壓結束

重點台灣中小型與櫃買跌幅已接近歷史級修正，但許多持有人只是回吐 4–5 月漲幅，仍有獲利可賣，未必會立刻出現典型投降量。
賣壓如何延長
  1. 韓國高槓桿去化向台、日、美科技與 AI 供應鏈外溢。
  2. 早期低成本持有人持續獲利了結，市場不一定一次爆量清洗。
  3. 個股跌破多條均線後，反彈還會遇到解套賣壓。
壓力區
櫃買指數 OTC 台灣中小型股 SMID SOX／AI 供應鏈 TECH
本集描述櫃買近一個月跌逾 20%、逼近 30%；這是錄音當下的主持人口述。
單日尾盤急拉或漲停家數增加，仍不足以證明趨勢已反轉。
風險：在流動性被抽乾時，把便宜當作止跌訊號，可能持續接到下落中的刀。
應對：等待量價、領漲族群與市場廣度同時改善，再提高個股風險。

單檔不超過 10%、提高指數與現金、停止槓桿

然後再來就是一定是不要再去使用槓桿
三層防守
  1. 集中度：單一持股壓到 10%以下。
  2. 工具：方向看不清時降低個股著墨，優先使用指數。
  3. 資金：反彈時才考慮增加台指期或現金；這是條件式計畫，不是已完成動作。

基本面最強也能崩：韓國去槓桿與評價制度改寫

重點Samsung、SK Hynix 與記憶體族群的展望仍佳，股價卻劇烈下跌；主持人把這視為流動性去化或市場提前反映未知風險的警訊，而非直接宣告基本面反轉。
兩條待驗證路徑
  1. 流動性路徑：韓國高槓桿清算尚未完成，便宜股仍被迫賣出。
  2. 產業路徑：市場可能提前交易中國供給、政策放行或獲利高峰。
  3. 確認方式：等待報價、訂單、資本支出與政策資料交叉驗證。

Agentic AI

CPU／GPU 走向 1:1，要看整個資料中心，不是單一 tray

重點Agentic AI 可把工作卸載到 general-purpose CPU racks／trays，CPU 增量應從整個 AI data center 計算；Helios compute tray 為 1 顆 EPYC Venice CPU 對 4 顆 Instinct MI455X GPU，整櫃則有 72 顆 MI455X。
所以它還是1比4
口徑拆解
  1. 產品層：Helios compute tray 為 1 顆 EPYC Venice CPU 搭 4 顆 Instinct MI455X GPU，仍是 1:4。
  2. 系統層：AI rack 外可追加 general-purpose CPU racks／trays 承接 Agentic 工作流。
  3. 資料中心層：把兩類設備合計後，整體 CPU／GPU 才有逐步靠近 1:1 的可能。
潛在受益
AMD AMD Intel INTC CPU／Socket SERVER
Helios 的 1:4 是 compute tray 配置；整櫃有 72 顆 MI455X，不可把 1:4 誤寫成整櫃或整座資料中心的最終比例。
管理層的 1:1 是方向性敘事，實際放量仍受產品時程與 CPU 產能約束。
風險：把長期資料中心口徑誤套到單一產品 BOM，會高估短期 CPU 放量速度。
應對：追蹤 general-purpose server 追加量、CPU 產能與實際 rack／tray 配置，而非只看管理層口號。

中國設備風險

DUV 不是新故事：真正閘門在 Apple／CSP 能否採用 CXMT

重點中國用 DUV 多重曝光推進較小線寬會犧牲成本、缺陷與良率；對全球供應鏈的衝擊取決於設備量產，以及美國是否允許 Apple 或 CSP 採用 CXMT 等中國零組件。
條件式情境
  1. 若維持封禁：中國設備與記憶體主要服務內需，外溢影響較有限。
  2. 若政策開門：低價產能可能進入 Apple／CSP 供應鏈，全球記憶體競爭升高。
  3. 錄音當下：Apple 遊說、CSP 測試與政府放行都不是已核准採用的事實。
觀察鏈
中國 DUV／EUV EQUIPMENT CXMT MEMORY Apple／CSP POLICY GATE
多重曝光能推進線寬，不代表成本、良率與量產能力已等同頂尖設備。
本段只保留主持人的條件式風險框架，不把傳聞改寫成已發生事件。
風險：將市場殺盤單因歸咎於 DUV 新聞，可能忽略整體盤面脆弱與去槓桿。
應對：只在政策文件、公司採用公告與量產資料出現後，才調高此風險情境的權重。

生存原則

新手不是做錯人：先縮部位，讓自己活過修正

重點六月才進場、買 0050 成分股卻虧損約 30%的聽眾，不等於選股或人格失敗；重點是不用槓桿、先用小部位認識承受度，並把生活品質列入風控。
風險絕對是放在獲利的前面
修正後的練習
  1. 若部位讓人吃不下、睡不著，先降低曝險，不等市場替自己解套。
  2. 把未實現損失視為沉沒成本，重新選擇較可能回到新高的工具。
  3. 維持研究節奏；行情轉好時，才有能力辨認下一輪領頭羊。

活過一次修正不保證獲利，但能保留修正策略與累積經驗的資格。

行動清單

本集可執行的三層檢查

現在先做

  • 把單一持股上限壓到 10%，總曝險調到不影響生活。

  • 美國是否正式放行 Apple／CSP 採用 CXMT 等中國零組件。
